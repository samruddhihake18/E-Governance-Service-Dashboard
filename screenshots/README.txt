To take a new screenshot:
1. Open dashboard/index.html in Chrome.
2. Select filters if you want (for example District = Sangli).
3. Press Windows + Shift + S (Windows) and select the area, or press F12 > Ctrl+Shift+P > type "Capture full size screenshot".
4. Save the image here as dashboard_preview.png.
